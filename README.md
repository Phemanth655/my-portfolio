# My Portfolio Website

A responsive portfolio website built with HTML and CSS.

## Features

- ✨ Responsive Design (Mobile-friendly)
- 🎨 Modern UI with Teal Color Scheme
- 📱 Flexible Navigation Menu
- 🎯 Service Cards Section
- 📄 Clean and Semantic HTML

## Project Structure

```
my-portfolio/
├── index.html      # Main HTML file
├── style.css       # Styling
└── README.md       # This file
```

## Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/Phemanth655/my-portfolio.git
   ```

2. Open `index.html` in your browser

## Deployment

### GitHub Pages (Recommended)
1. Go to your repository Settings
2. Navigate to **Pages** section
3. Select **main** branch as source
4. Your site will be live at: `https://Phemanth655.github.io/my-portfolio`

### Alternative Deployment Options
- **Netlify:** Connect your GitHub repo for automatic deployments
- **Vercel:** Import project for instant hosting
- **Any Web Host:** Simply upload HTML and CSS files via FTP

## Customization

- **Colors:** Edit the `#008080` (teal) color codes in `style.css`
- **Content:** Update text in `index.html`
- **Links:** Update navigation links in the `<nav>` section

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
